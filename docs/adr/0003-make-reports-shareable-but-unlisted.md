# Hacer los informes compartibles pero no listados

Cada investigación tendrá una URL con un identificador corto de alta entropía y cualquiera que posea el enlace podrá abrirla, pero los informes no aparecerán en directorios, búsquedas internas ni índices de buscadores. Al no existir autenticación, este modelo permite compartir resultados sin afirmar una privacidad que el producto no puede garantizar; la URL será el único medio de acceso y recuperación.
