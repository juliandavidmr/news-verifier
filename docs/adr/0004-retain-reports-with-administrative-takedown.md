# Conservar informes sin caducidad y permitir retirada administrativa

Los informes no caducarán y el MVP no ofrecerá eliminación iniciada por el usuario, de modo que sus URLs compartibles permanezcan estables. Se conservarán el informe, el Extracto analizado y la evidencia necesaria para auditarlo, pero se eliminarán los archivos de imagen originales y sus metadatos después del procesamiento; para responder a riesgos legales, de privacidad y abuso, el footer permitirá reportar contenido y el operador podrá ocultar o eliminar un informe.
