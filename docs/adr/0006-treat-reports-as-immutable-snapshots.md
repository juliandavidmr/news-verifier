# Tratar los informes como instantáneas inmutables

Cada informe será una instantánea permanente rotulada con la fecha y hora de la investigación y nunca se recalculará silenciosamente cuando cambien el contenido, las fuentes o el conocimiento disponible. El MVP no ofrecerá un botón para volver a investigar; esta inmutabilidad mantiene reproducible el significado de una URL y evita que un resultado histórico se presente como una evaluación actual.
